# Milestones and deadlines

The project accounts for 30% of the ADA course grade. P1 is submitted individually through a Google Form; P2 and P3 are team submissions collected from the project GitHub repository.

## P1 — Project ideas

- **Deadline:** Friday, 2 October 2026 at 23:59 CET
- **Weight:** 10% of the project
- **Work mode:** Individual
- **Submission:** [P1 Google Form](https://docs.google.com/forms/d/e/1FAIpQLSdGOHtzdLSG_aWXQTUsCsviIyMXU-vTHHxoHgdGSS1EjSkNNg/viewform?usp=publish-editor)

Before submitting:

1. Read the paper associated with the selected dataset and understand how the data was derived.
2. Explore samples and summary statistics. An in-depth analysis of the complete dataset is not required for P1.
3. Propose exactly three bold and creative project ideas. Each idea should state:
   - a title and overall goal;
   - high-level research questions;
   - high-level solution steps for each question.

**Deliverable:** An outline of up to 500 words. P1 code is not graded. Ideas submitted for P1 do not have to become the final team project.

## P2 — Proposal and initial analysis

- **Updated deadline:** Friday, 6 November 2026 at 23:59 CET
- **Weight:** 20% of the project
- **Work mode:** Team
- **Submission:** Repository under the [`epfl-ada`](https://github.com/epfl-ada) GitHub organization

The team should refine and verify the feasibility of its chosen project. The work should demonstrate that the team can handle and understand the data, including its formats, distributions, missing values, and correlations; consider appropriate enrichment, filtering, and transformations; describe the essential mathematical details of planned methods; and present a reasonable analysis and communication plan.

The repository should follow the [ADA project template](https://github.com/epfl-ada/project_template) and contain:

- a well-organized `README.md` with a detailed proposal of up to 1,000 words:
  - title;
  - abstract of approximately 150 words;
  - research questions;
  - proposed additional datasets, if any, including acquisition, format, size, processing, and feasibility;
  - methods;
  - proposed timeline;
  - organization and internal team milestones through P3;
  - optional questions for the TAs;
- initial analyses and documented data-handling pipelines;
- one Jupyter notebook presenting the main initial results;
- external scripts or modules containing the main implementation logic called by the notebook.

## P3 — Final project and data story

- **Deadline:** Friday, 18 December 2026 at 23:59 CET
- **Weight:** 70% of the project
- **Work mode:** Team

The final submission consists of:

1. The project repository with final code and an extended results notebook. The main implementation logic should remain in external scripts or modules.
2. A public-facing data story with a strong visual component, published using a platform of the team's choice. The story URL should be included in the final `README.md`.

The final README should also identify each team member's contributions. The data story may be less formal than the notebook, while technical methods and mathematical details should remain documented in the notebook.
